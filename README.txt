INVITACIÓN - PRESENTACIÓN DE UN NIÑO CRISTIANO
==============================================

Cómo usar:
1. Abre el archivo "index.html" en cualquier navegador.
2. ¡Listo!

Personalizar:
- Cambia la fecha, hora, iglesia y nombre del niño en el archivo index.html
- Cambia el número de WhatsApp en el botón de confirmar asistencia
- Puedes modificar el mensaje y el versículo si lo deseas

Imágenes incluidas (carpeta /imagenes):
- cruz.svg       → Cruz dorada
- paloma.svg     → Paloma con rama de olivo
- biblia.svg     → Biblia con cruz
- corazon.svg    → Corazón
- estrella.svg   → Estrella dorada
- globo1.svg     → Globo azul
- globo2.svg     → Globo morado
- globo3.svg     → Globo verde

Todas las imágenes son SVG (vectoriales).
